# Ruta de aprendizaje PHP

Ejercicios y prácticas de mi ruta de aprendizaje de PHP, organizados por tema.

| Carpeta | Contenido |
|---|---|
| `curso basico de php_instalacion, funcadmentos y operadores` | Sintaxis, tipos de datos, variables y operadores |
| `Fundamentos de PHP` | Estructuras de control y fundamentos del lenguaje |
| `curso PHP arreglos,funciones y estructuras` | Arreglos, funciones y estructuras de datos |
| `Curso de manejo de datos en PHP` | Manejo de cadenas, expresiones regulares y validación |
| `entornos virtuales y funciones avazadas` | Funciones avanzadas y configuración del entorno |
| `POO` | Programación orientada a objetos: herencia, abstracción e interfaces |
| `PHP con composer` | Manejo de dependencias y autoload con Composer |
| `curso practico PHP` | Ejercicios prácticos |
| `ahorcado_juego` | Juego del ahorcado en PHP |
| `hosting` | Versión del sitio personal preparada para despliegue |
| `Copilot` | Pequeñas APIs de práctica en Go y Python con pruebas unitarias |

**Stack:** PHP 8, Composer, Git.
